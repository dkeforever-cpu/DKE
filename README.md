# 물류센터 업무관리 시스템 (프로토타입)

관리팀·재경팀 업무 협업 트래커 클릭 테스트용 프로토타입입니다. 로그인 → 대시보드(부서 탭 · 사이드바 카테고리 ·
필터) → 업무 상세(진행 일지 + 댓글, 수정/삭제 권한)까지 실제로 클릭해볼 수 있습니다.

데이터는 브라우저 `localStorage`에 저장되는 목업 데이터입니다(실제 서버/DB 없음). 로그인 화면에서 계정을
선택하면 바로 로그인되고, "테스트 데이터 초기화" 버튼으로 언제든 시드 데이터로 되돌릴 수 있습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속.

## 주요 화면

- `/login` — 테스트 계정 선택 로그인
- `/` — 대시보드 (전체/관리팀/재경팀 탭, 좌측 내 업무·전체 업무·카테고리 메뉴, 필터, 업무 등록)
- `/tasks/[id]` — 업무 상세 (진행 일지 작성/수정/삭제, 일지별 댓글, 첨부파일)

## 권한 규칙

- 업무는 누구나 등록/배정 가능하며, 본인 업무는 담당자 본인이 자유롭게 수정합니다.
- 진행 일지·댓글은 작성자 본인 또는 관리자 권한 계정만 수정/삭제할 수 있고, 등록 횟수 제한은 없습니다.
