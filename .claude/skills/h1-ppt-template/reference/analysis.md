| 용도 | 색상 | HEX (근사) |

| Body 배경 (전 슬라이드 공통) | 크림/아이보리 (은은한 종이 텍스처) | `#F8EDDB` |
| Accent — 카퍼/브론즈 메탈릭 (제목, 라인, 테두리, 강조 박스) | 카퍼 미드톤 | `#D18E5A` (그라데이션: 어두운 브론즈 그림자 ~ 밝은 골드 하이라이트 `#FFFACA` 근처까지) |

| 본문 제목/헤딩 텍스트 (크림 배경 위) | 블랙 계열 | `#1A1A1A`~`#000000` |
| 테이블 헤더 밴드 | 탠/베이지 | `#EFDDC7` |
| 테이블 바디 행 | 오프화이트 크림 | `#FEFAEE` |
| 테이블 내 강조 숫자(평수 등) | 코랄/살몬 레드 | `#FAB781` 톤 계열 |
| 도면(플로어플랜) 배경 | 화이트, 얇은 회색 테두리 | `#FFFFFF` / 그레이 라인 |
| 안내 박스("임대완료" 등) | 다크 네이비 배경 + 화이트 텍스트 | `#182F51` bg / `#FFFFFF` text |

**규칙**: 새 슬라이드에서 색은 반드시 위 팔레트 안에서만 사용합니다. 새로운 색이 필요해 보여도
먼저 카퍼 accent 또는 네이비가 그 역할을 할 수 있는지 검토하고, 사용자가 명시적으로 새 색을
요청한 경우에만 예외를 둡니다.

## 2. 타이포그래피

- **한글 제목(슬라이드 타이틀)**: 매우 두꺼운 고딕 계열(Bold/Black), 카퍼 메탈릭 그라데이션 +
  엠보싱(입체) 효과. 예: "사업 개요", "입지 환경", "프리미엄의 정점", "층별 권장 업종", "층별 면적표".
- **영문 서브타이틀**: 타이틀 바로 아래, 볼드 산세리프, 자간(letter-spacing) 넓힘, 전부 대문자,
  라이트 블루그레이 색. 예: "PROJECT OVERVIEW", "LOCATION ENVIRONMENT".
- **표지(Cover) 타이틀**: 한글+영문 혼합, 초대형 카퍼 메탈릭 엠보싱 텍스트("의왕 THE H1 TOWER"),
  그 아래 볼드 서브카피(블랙) + 우측 상단에 작은 영문 라벨.
- **본문 헤딩(라벨)**: 한글 볼드 + 옆에 작은 영문 캡션 (예: "위치 LOCATION", "규모 및 면적 SCALE & GFA").
- **본문 텍스트**: 미디엄 웨이트 고딕, 블랙 또는 화이트(네이비 배경 위), 여백을 넉넉히 둔 짧은 문장.
- **표 텍스트**: 작고 균일한 고딕, 숫자는 우측 정렬, 합계/소계 행은 볼드.

폰트가 정확히 무엇인지는 임베딩 정보로 확인 필요(추정: Pretendard/Noto Sans KR 계열 Bold~Black
웨이트). 정확한 폰트를 알 수 없을 때는 위 두께·크기 위계만 최대한 재현합니다.

## 3. 반복 구조 요소

### 3-1. 표준 슬라이드 헤더 (거의 모든 내지 슬라이드에 공통)
- 상/하 얇은 카퍼 더블라인 보더
- 네이비 배경 바(슬라이드 상단 ~18~20%)
- 중앙 정렬: 한글 타이틀(카퍼 엠보싱, 대형) + 영문 서브타이틀(라이트 블루그레이, 자간 넓음)

### 3-2. 푸터
- 우측 하단에 항상 "의왕 THE H1 TOWER" 워드마크(카퍼 텍스트, 작게)

### 3-3. 강조 박스
- 카퍼 더블라인 보더의 박스, 크림 배경, 안에 "[ TAG ]" 라벨(영문 대문자, 브라켓) +
  대형 볼드 헤드카피 + 작은 서브카피. (사업개요 슬라이드의 "EXCLUSIVE MANAGEMENT" 박스)

|---|---|---|---|
| L1 | **표지 (Cover)** | p.1 "의왕 THE H1 TOWER" | 풀블리드 건물 렌더링 이미지, 하단 화이트→투명 그라데이션 밴드 위에 카퍼 엠보싱 대형 타이틀 + 블랙 볼드 서브카피 + 우측 영문 라벨 |

| L3 | **좌:지도/이미지 + 우:아이콘 리스트** | p.3 "입지환경" | 표준헤더 + 좌측 큰 지도/이미지 패널(보더) + 우측 세로 리스트(아이콘+영문헤딩+한글 불릿, 카퍼 라인으로 구분) |

| L6 | **복합 헤더 데이터 테이블** | p.6 "층별면적표" | 표준헤더 + 다단(멀티레벨) 헤더 테이블, 탠 헤더밴드, 합계행 볼드 강조 |
| L7 | **좌:도면 + 우:네이비 정보 사이드바** | p.7~11 (1F/2F-6F/구분임대/2호임대시/1호임대시) | 좌측(~65%) 크림 보더 안 건축 평면도(방위표시, 치수, 실명, 동선화살표) / 우측(~35%) 네이비 풀컬러 사이드바: 층 라벨 + 2줄 볼드 헤드라인 + 화이트 본문 + "[권장업종]" 태그+리스트 + 2×2 이미지 그리드 + 우하단 워드마크 |
| L8 | **클로징/컨택트** | p.12 "문의" | 상단 네이비 밴드(2줄 볼드 카피, 화이트+카퍼 강조) + 카퍼 구분선 + 크림 바디(중앙 볼드 카퍼 2줄 카피) + "문의하는곳" 헤딩 + 담당자별 아이콘+연락처 행 |
| L9 | **플레인 타이틀 + 대형 재무표** | p.13~14 "THE H1 면적 및 임대료 기준표" | 표준헤더 없이 좌상단 플레인 볼드 타이틀만, 전체 화면을 채우는 초고밀도 다단 표(층별 그룹 배경밴드, 소계/합계 행 볼드, 보증금/임대료 우측 별도 구획) |

**레이아웃 선택 우선순위**: 새 슬라이드 요청이 오면 위 L1~L9 중 콘텐츠 성격이 가장 가까운
레이아웃을 고르고, 없으면 가장 유사한 레이아웃의 그리드/타이포/색을 유지한 채 최소한으로
확장합니다. 완전히 새로운 레이아웃은 최후의 수단입니다.
