# 체크포인트: 정상 작동 확인됨 (2026-09-07)

이 커밋(`1529489` 및 그 이후 이 파일이 안 바뀐 커밋들)의 `apps-script/` 내용은
사용자가 실제 배포 환경(구글 앱스크립트 웹 앱)에서 로그인, 대시보드, 첨부파일
업로드까지 정상 작동을 직접 확인한 버전입니다.

## 포함된 기능
- 구글 시트를 DB로, 구글 드라이브를 파일 저장소로 사용하는 백엔드 연동
- 로그인 / 팀·게시판·카테고리 구조 / 업무 등록·상세·체크리스트·댓글
- 진행 일지·댓글 첨부파일의 실제 드라이브 업로드 (업무번호별 하위 폴더 정리),
  단 **조각 전송(chunked) 방식만** 사용 — 업로드 등록 버튼을 누를 때만 전송 시작
- 가져오기(import) 시 기존 데이터 전체 교체 + 날짜 서식 깨짐 방지

## 포함되지 않은 것 (의도적으로 제외)
- 구글 드라이브 "직접 업로드(빠른 경로)" 기능 — `google.script.run` +
  `ScriptApp.getOAuthToken()` 기반. 이 기능을 추가한 이후 버전들에서
  반복적으로 실행 환경에서만 재현되는 "OO is not defined" 런타임 에러가
  발생해(로컬 테스트로는 재현 안 됨) 이 시점으로 롤백하며 함께 제거했다.
  다시 시도한다면 반드시 사용자 환경에서 배포 후 충분히 검증한 뒤 유지할 것.
- `google.script.run` 존재 여부를 화면에 표시하는 진단 UI — 위 기능과 함께 제거.
